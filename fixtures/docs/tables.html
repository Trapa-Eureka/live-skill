Lab Freezer Operating Notes

This fictional note describes the FrostBox 40 sample freezer used only as a test fixture.

Temperature Limits

Keep the chamber between the limits below.
Chamber limits by mode
Mode Minimum Maximum
Storage -40 °C -30 °C
Defrost -5 °C +4 °C

Startup Procedure

  1. Close the lid and latch it.
  2. Press POWER and wait for the status LED.
    • Green means ready.
    • Amber means still cooling.
  3. Log the start time on the sheet.

Alarm Codes

# E01 lid open longer than 90 seconds
E02 compressor overload
Silence an alarm only after the cause is written down.
